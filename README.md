# Grammy

Grammy is a Mac menu bar app that turns a sentence into a hand-drawn diagram. Double-tap right ⌘,
describe the diagram, and it's on your clipboard, ready to paste into Slack, a doc or an email.

**[Download Grammy.dmg](https://github.com/amanmathur99/grammy-releases/releases/latest/download/Grammy.dmg)**

Requires macOS 14 or later and an [Anthropic API key](https://console.anthropic.com/settings/keys).
It's signed and notarized by Apple.

## Install

1. Open **Grammy.dmg** and open Grammy.
2. Grammy offers to move itself to Applications. Say yes.
3. A short setup walks you through your API key, permissions, and your first diagram.

## Updating

Download the latest **Grammy.dmg** and open it. Grammy replaces the old copy and keeps your key,
settings and history.

Every version is listed under [Releases](https://github.com/amanmathur99/grammy-releases/releases).

## Privacy

Your descriptions go straight from your Mac to Anthropic, using your own API key. Grammy
anonymously counts how often it's used, never what you draw. You can turn this off in
Settings → Privacy.
